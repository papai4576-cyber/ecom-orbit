# Changelog — Ecom Orbit Website

*Running record of shipped changes, newest first. One entry per change with a one-line reason. Update this in the same pass as the change itself — see "Single Source of Truth" in `CLAUDE.md`.*

---

- **Removed vanity scale stats, reframed around founder-led positioning:** Replaced "₹50Cr+ Revenue Generated" and "200+ Brands Launched" (hero, stats-strip, ticker, about, free-audit) with "2 Founders on Every Account" / "Founder-Led, Not Agency-Run" / "Direct Access to Your Strategists"; free-audit's "200+ Indian brands have gotten this audit" line reworded to "Every audit is done personally by one of our two founders." Updated `brand-context.md` stats table and added a "Team size / scale" note documenting the real state (2 founders, ~10–12 brands worked with) so future copy doesn't drift back to inflated numbers. *Why: the agency is a 2-person consultancy with 10–12 real clients — ₹50Cr+/200+ read as big-agency numbers that don't hold up and weren't true.*
- **Docs governance:** Fixed `CLAUDE.md` referring to a non-existent `agent_docs/` folder (actual folder is `agents_docs/`); removed stale WhatsApp-CTA "not optional" and "Chat on WhatsApp" CTA rules that contradicted the current disabled state; added the "Single Source of Truth" process section and this changelog. *Why: docs had drifted from the live site and were actively misdirecting future work.*
- **brand-context.md:** Added "Live Status & Contact Facts" section (live domain, contact email, contact-form mechanism, WhatsApp/case-studies disabled status, D2C-framing and exclusivity-claim rules); fixed a stray "Indian D2C stores" stat wording to match the live "Indian ecommerce stores" copy. *Why: these facts existed only in code, not in any doc — no single source of truth for them.*
- **Softened exclusivity claims:** Hero eyebrow "India's Only 7-Channel Ecommerce Agency" → "India's 7-Channel Ecommerce Agency"; multi-channel pull quote "the only SMB agency in India..." → "runs marketplaces, your website, and quick commerce as one system..."; softened the same claims in `brand-context.md` differentiators #1 and #4. *Why: unsubstantiated "only"/"nobody else" claims are hard to defend and read as overreach.*
- **Softened D2C-first framing site-wide:** Hero headline "Your D2C Brand" → "Your Business"; browser tab title/meta descriptions broadened from "for D2C brands" to "for online brands and offline retailers" / "ecommerce brands"; stats strip, problem section, marketplace spotlight, services grid, about page copy de-D2C'd. *Why: "D2C" in headline-level copy reads as Shopify-only/online-native-brand positioning and undersells the offline-to-online side of the business.*
- **Went live on production domain:** Promoted to `ecomorbit.in` / `www.ecomorbit.in`. Added apex + www domains to the Vercel project, pointed DNS (A records → `76.76.21.21`) at the registrar, manually triggered SSL certificate issuance via `vercel certs issue`. *Why: user requested going live on the original domain.*
- **Contact form → Google Sheet integration:** `/api/contact` now POSTs validated submissions to a Google Apps Script Web App webhook (`GOOGLE_SHEETS_WEBHOOK_URL` env var) that appends rows to a Google Sheet; created the sheet with header row via Google Drive API; verified end-to-end (form → API route → webhook → sheet row) after working through a Vercel CLI env-var-scoping issue and a Google Apps Script POST-redirect false alarm. *Why: contact form previously only logged submissions to server console — no durable record of leads.*
- **Removed fake case studies site-wide:** Deleted `/case-studies` (index + 6 detail pages, now 404s), the homepage case-studies section, and the founder-testimonials section (fabricated quotes tied to the same placeholder brands); removed "mini case study" callouts from service pages and "Results in [industry]" blocks from industry pages; removed "Case Studies" from nav/footer links. *Why: the client stories were placeholder/fabricated, not real client data — user asked for them removed until real ones exist.*
- **Removed WhatsApp CTA site-wide:** Floating WhatsApp button, nav icon (desktop + mobile), footer pill, CTA-section secondary button, final-CTA button, pricing feature line, contact-page WhatsApp panel — all removed; contact-form error copy and page copy reworded to not reference WhatsApp as a contact method. *Why: user does not want a WhatsApp-first contact impression right now.*
- **Fixed two live bugs:** Nav "Services" dropdown had a hover gap (`margin-top` outside the hoverable area) that closed the menu before users could click into it — fixed by making the gap `padding` inside the hover region instead. Hero's orbit-diagram background was rendering at too high an opacity with solid node circles, visually colliding with the headline text — reduced peak opacity from ~90% to ~22%, added blur, removed redundant opacity stacking.
- **Homepage visual pass:** Added a browser-mockup illustration to the Services section, a scattered-nodes-vs-orbit-diagram "before/after" visual to the Problem section, animated revenue bars to case-study preview cards and the Quick Commerce section — replacing plain icon+text card grids with more varied, less templated visuals. Built reusable Framer Motion primitives: `BrowserMockup`, `BarCompare`, `ScatterDiagram`.
- **Full site build-out:** Built out the full documented sitemap (7 service pages, 4 industry pages, case-studies index + details, blog index + 6 seed posts, about, contact with form, free-audit landing) as data-driven `[slug]` routes; rewrote `content-copy.md` for sharper, less templated copy; added Framer Motion animation primitives (`OrbitDiagram`, `PinnedSection`, `ParallaxLayer`, `CountUp`, `Reveal`) replacing the homegrown IntersectionObserver pattern; added `sitemap.ts`, `robots.ts`, favicon, per-page metadata. *Why: only the homepage existed — every nav/footer link 404'd; the homepage itself read as generic/AI-templated.*
- **Initial Vercel deployment:** Deployed the pre-existing homepage-only site to a Vercel preview to establish a baseline before further work.
